# YarnBeacon

YarnBeacon enables scalable, distributed, and fault-tolerant stateful-stream-processing of yarn data via containerized-deployment.

With YarnBeacon, you get a lightweight tool that stays out of your way.

**What you get**

- YarnBeacon enables scalable, distributed, and
- fault-tolerant stateful-stream-processing of yarn data
- via containerized-deployment

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/YarnBeacon.git`
2. `cd YarnBeacon`
3. Install in editable mode: `pip install -e .`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
